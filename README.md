# AIML Assignments Repository

A comprehensive collection of systematic solutions for Artificial Intelligence and Machine Learning (AIML) assignments. Each assignment is self-contained with theory, step-by-step frameworks, numerical examples, Python code snippets, evaluation metrics, and conclusions.

---

## Overview

This repository is designed to help students, educators, and practitioners understand and implement core AIML concepts through practical, well-documented solutions. Every assignment follows a consistent structure: introduction, theory, systematic framework, numerical example, Python implementation, interpretation guidelines, and conclusion.

---

## Assignments

| No. | Topic | Key Concepts |
|-----|-------|--------------|
| 01 | Association Analysis | Pearson correlation, Chi-square, ANOVA, Mutual Information |
| 02 | Clustering | K-Means, DBSCAN, Hierarchical, GMM, Silhouette Score |
| 03 | Dimensionality Reduction | PCA, Eigenvalues, Scree Plot, Explained Variance |
| 04 | Naive Bayes | Gaussian, Multinomial, Bernoulli, Bayes Theorem |
| 05 | KNN Classification | Distance Metrics, Optimal K, Feature Scaling |
| 06 | Linear Regression | OLS, MSE, R-squared, Residual Analysis |
| 07 | SVM Regression | Epsilon Tube, Kernels, Hyperparameter Tuning |
| 08 | Regularization | Ridge, Lasso, Elastic Net, Coefficient Paths |
| 09 | Object Detection (CCTV) | YOLOv8, IoU, NMS, mAP, Tracking |
| 10 | Fake News Detection | BERT, ResNet, CLIP, Multimodal Fusion |

## Tech Stack

- **Language:** Python 3.9+
- **Data:** NumPy, Pandas
- **Visualization:** Matplotlib, Seaborn
- **ML:** Scikit-learn, SciPy, Statsmodels
- **DL:** PyTorch, Transformers
- **CV:** OpenCV, Ultralytics YOLOv8

## Installation

```bash
git clone https://github.com/your-username/AIML-Assignments.git
cd AIML-Assignments
pip install -r requirements.txt
```

## Usage

Open any assignment markdown file and run the code snippets in Jupyter Notebook or Google Colab. Each file is independent and includes all necessary imports.
